# Minigame 1
## Devlog
Think of Scene as a stage set. Each GameObject is an actor or prop placed on that stage, and its Components are what give it its role and abilities: a Transform decides where it stands, a Sprite Renderer gives it an appearance, and a script can make it act. Put the objects together, and they make the Scene.
